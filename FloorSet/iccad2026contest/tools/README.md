# Feasibility diagnostics

Scripts behind every number in `../../../FEASIBILITY_ANALYSIS.md`.
Run from `FloorSet/iccad2026contest/` with the `iccad` conda env active.
They import the contest tree by absolute path, so `python tools/<script>.py` works.

| script | what it measures |
|---|---|
| `diag_testkit.py <data_path>` | per-case H1–H4 breakdown (overlap / area / fixed / preplaced-dim / preplaced-pos) + which pairs overlap and whether an immutable block is involved. Reads `manifest.json` for case names when present. |
| `repro_case.py <ids>` | per-seed legalization signature on stress-kit cases: `repair_failures`, `assign_failures`, `final_assignment_ok`, penetration, offending pairs. |
| `constraint_stats.py` | constraint-density distributions: official validation vs sampled training shards (preplaced/fixed/boundary fractions, MIB/cluster groups, heterogeneous-area MIB groups). |
| `mib_stats.py` | intra-MIB-group target-area spread, and how many training layouts blind dimension tying would make area-infeasible (the beta root cause). |
| `proto_fallback.py <ids>` | scores two guaranteed-feasible re-pack constructions (shelf-above-obstacles, free-rectangle first-fit) with the official formula. |
| `proto_evict.py <ids>` | scores the targeted-eviction repair: relocate only the blocks that overlap an immutable anchor. |
| `ab_legalize.py <preds.json>` | fast deterministic A/B of legalizer configs over cached predictions — the inner loop for legalizer tuning. Dump candidates once with `python -m floordiff.sample --save-topk 24 --n-seeds 32`, then sweep with `--variants variants.json` or a single `--cfg '{...}'`. Reports the runtime-neutral official total, mean cost, V_rel / area / hpwl breakdown, and stage-E firing. Noise floor is ~±0.0005 on the total (the DP stages carry wall-clock budgets), so treat anything under ±0.001 as a tie. |
| `val_evict.py <out.json> [device]` | walks all 100 official validation cases (one candidate each, deterministic) and reports whether stage E fires — evictions, floor uses, reclaim moves — plus per-case cost and legalize time. Set the `CFG` env var to a JSON object turning `evict_repair`, `guaranteed_floor` and `reclaim` off for the control arm; identical per-case costs across the two arms is the no-regression proof. |
| `val_graph.py <block_counts>` | graph-repair status (`repair_failures`, `assign_failures`, `final_assignment_ok`) on official validation cases — shows where the eviction path would fire on cases that currently pass. |

`<ids>` is a comma-separated test-id list. The 16 stress-kit cases that fail today:
`6,8,19,26,27,33,34,35,36,37,40,41,48,49,54,55`.
Default data path for the prototypes is `cadc1111/floorset_testkit` (generated by
`cadc1111/gencase.py`).


## Measured: stage G and relation-graph construction (2026-08-25)

Swept over cached predictions for the official 100 (`ab_legalize.py`), runtime-neutral total,
baseline 1.0496. **Nothing in stage G or in the per-pair axis rule beat the current settings;
the only real gain was iterating the graph rebuild.**

| variant | total | Δ | per-case |
|---|---|---|---|
| baseline (`g_iters=100`, rule `gap`, 2 rounds) | 1.0496 | — | — |
| **`legal_rounds: 3`** | **1.0469** | **−0.0031** | **16 better, 1 worse** |
| `legal_rounds` 4 / 6 | 1.0474 | −0.0026 | saturates at 3 |
| `g_iters` 0 / 50 / 200 / 400 | 1.0532 / 1.0515 / 1.0516 / 1.0510 | +0.0015…+0.0036 | G off is worse on 61/100 |
| `g_omega` 0.6 / 1.0 | 1.0536 / 1.0516 | +0.0040 / +0.0020 | |

| `graph_rule: norm` | 1.0488 | −0.0007 | 10 better, 13 worse — a wash |
| `graph_rule: anchor` | 1.0496 | 0.0000 | inert at 4% anchors |
| `graph_rule: square` k=0.15…1.0 | 1.0467…1.7279 | −0.0029…+0.6783 | **harmful**, see the code note |
| `graph_key: edge` | 1.0570 | +0.0074 | centre ordering is better |

Where the remaining cost actually is (official 100, weighted, multiplicative):
**violations +2.72%** (45 boundary, 11 grouping, 0 MIB — boundary is the lever),
**bbox area +1.58%**, hpwl +0.31%. For reference the ground-truth layout itself scores
**1.1079** with 219 boundary violations, so we already beat it by a wide margin on
boundary — but its area gap is 0 by definition, which is where our 1.58% lives.


## Measured: what stage E sacrifices, and what compensates (2026-08-25)

Attribution over the 156 stress cases (`analyze_evict.py`, budgets neutralised). Stage E fired on
72 selected candidates; it fires on **4/200 regular** and **0/100 official**.

**Marginal cost of the guarantee**, controlling for anchor density (eviction vs clean cases in the
same preplaced band): **+0.22 / +0.27 / +0.14** at 15-30% / 30-45% / 45-60% preplaced. The raw
gap (2.19 vs 1.59) is mostly difficulty, not eviction.

**Where the damage lands** (eviction cases; 5.9 blocks evicted on average, 7.7% of blocks):

| term | measurement | verdict |
|---|---|---|
| HPWL / locality | evicted blocks carry **24.2%** of total wirelength and sit **0.497·S** from their netlist barycentre | the dominant damage |
| area | excess area gap over comparable clean cases +0.085, of which the shelf itself is **+0.061 (72%)**, core degradation +0.024 | second |
| grouping | **68 of 91** split groups contain an evicted member — but only 1.6 violations/case | small in absolute terms |
| boundary | **4 of 590** violations on evicted blocks (1%); 50 evicted blocks carried a boundary bit and kept it | **free** — the shelf sits on the bbox's top edge |
| MIB | unaffected (dims are preserved by eviction) | none |

**Compensations tried** (stress kit, deterministic):

| change | total | Δ | per case |
|---|---|---|---|
| baseline (reclaim, no re-round) | 1.6938 | — | — |
| **`reclaim_round: True`** — re-run one legal round after E-2 so stage S and DP-1 see the reclaimed blocks (and the graph-slack invariant is restored) | **1.6633** | **−0.0305** | **53 better, 0 worse** |
| `evict_shelf: auto` (shelf on the cheaper bbox side) | 1.7833 | +0.0894 | 23 better, 42 worse — **refuted** |
| `evict_weights` boundary 0 / 1, cluster 4 | 1.6714 / 1.6733 | +0.008 / +0.010 | **refuted** |
| `evict_weights` boundary 0, cluster 2 | 1.6714 | +0.008 | refuted (identical to boundary 0 / cluster 4 — once the boundary term is gone the cluster term no longer decides the argmin) |
| `evict_weights` cluster 8, degree 4 (protect groups harder) | 1.6760 | +0.013 | **worst of the five** |
| `reclaim_probe` 16 + `reclaim_trials` 48 | +0.0008 vs its own base | ~0 | no gain |

Two lessons worth keeping:

* The shelf-above position is **load-bearing**, not incidental: it is why eviction costs no boundary
  violations. Any redesign that moves evicted blocks inside the layout must pay that back.
* The 1% boundary attribution exists **because** `_eviction_score` protects boundary blocks — removing
  that protection makes it worse. An attribution measured under a policy cannot be used to argue the
  policy is unnecessary.

**Open, and the most promising remaining lead**: in production `reclaim_budget_s = 0.05` throttles
the reclaim pass, so the end-to-end gain was only −0.0036 against the harness's −0.0305. Raising it
(0.15-0.30 s) should convert most of that gap, and the runtime economics allow it on exactly the
cases where E fires. **Must be measured on an idle box** — a wall-clock-budget test is meaningless
at load average 60.
