# Feasibility diagnostics

Scripts behind every number in `../../../FEASIBILITY_ANALYSIS.md`.
Run from `FloorSet/iccad2026contest/` with the `iccad` conda env active.
They import the contest tree by absolute path, so `python tools/<script>.py` works.

| script | what it measures |
|---|---|
| `diag_testkit.py <data_path>` | per-case H1–H4 breakdown (overlap / area / fixed / preplaced-dim / preplaced-pos) + which pairs overlap and whether an immutable block is involved. Reads `manifest.json` for case names when present. |
| `repro_case.py <ids>` | per-seed legalization signature on stress-kit cases: `repair_failures`, `assign_failures`, `final_assignment_ok`, penetration, offending pairs. |
| `constraint_stats.py` | constraint-density distributions: official validation vs sampled training shards (preplaced/fixed/boundary fractions, MIB/cluster groups, heterogeneous-area MIB groups). |
| `mib_stats.py` | intra-MIB-group target-area spread, and how many training layouts blind dimension tying would make area-infeasible (the beta root cause). |
| `proto_fallback.py <ids>` | scores two guaranteed-feasible re-pack constructions (shelf-above-obstacles, free-rectangle first-fit) with the official formula. |
| `proto_evict.py <ids>` | scores the targeted-eviction repair: relocate only the blocks that overlap an immutable anchor. |
| `val_evict.py <out.json> [device]` | walks all 100 official validation cases (one candidate each, deterministic) and reports whether stage E fires — evictions, floor uses, reclaim moves — plus per-case cost and legalize time. Set the `CFG` env var to a JSON object turning `evict_repair`, `guaranteed_floor` and `reclaim` off for the control arm; identical per-case costs across the two arms is the no-regression proof. |
| `val_graph.py <block_counts>` | graph-repair status (`repair_failures`, `assign_failures`, `final_assignment_ok`) on official validation cases — shows where the eviction path would fire on cases that currently pass. |

`<ids>` is a comma-separated test-id list. The 16 stress-kit cases that fail today:
`6,8,19,26,27,33,34,35,36,37,40,41,48,49,54,55`.
Default data path for the prototypes is `cadc1111/floorset_testkit` (generated by
`cadc1111/gencase.py`).
